1. 셸 스크립트와 자동화

셸 스크립트(Shell Script): 여러 명령어를 파일에 작성하여 한 번에 실행할 수 있도록 하는 방법이다.
자동화: 반복적인 작업을 스크립트로 실행하여 시간을 줄이고 실수를 방지한다.
#!/bin/bash: Bash로 스크립트를 실행하도록 지정하는 셔뱅(Shebang)이다.

2. Qwen과 Ollama
Qwen: 질문에 대한 답변을 생성하는 AI 모델이다.
Ollama: 로컬 컴퓨터에서 AI 모델을 설치하고 실행할 수 있도록 해주는 도구이다.
qwen3:0.6b 모델을 다운로드하고 Ollama 서버를 실행하여 AI 서비스를 사용할 수 있다.

3. 파이썬 웹 프로그램 실행
chat.py: 브라우저에서 질문을 입력하고 AI의 답변을 확인할 수 있는 파이썬 웹 프로그램이다.
웹 브라우저에서 http://localhost:8000에 접속하여 사용할 수 있다.

4. 셸 스크립트 작성 및 실행
start.sh 파일에 실행 명령어를 작성하여 프로그램을 간편하게 실행할 수 있다.

5. 환경 변수와 조건문
환경 변수: 프로그램의 실행 설정을 전달하는 데 사용한다.
조건문: 프로그램이나 명령어의 설치 여부를 확인하고, 조건에 따라 다른 동작을 수행한다.
