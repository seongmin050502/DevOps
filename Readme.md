1. 네트워크 실습

net_check.sh: IP, DNS, HTTP 응답 및 포트 확인
start_server.sh: 로컬 웹 서버 실행
check_server.sh: 서버 응답 및 포트 상태 확인

2. 자동화 및 협업 실습
backup.sh: 파일 및 디렉터리 백업
check_path.sh: 파일과 디렉터리 존재 여부 확인
search_examples.sh: find, grep 명령어 실습
sample_server.log: 로그 검색 연습용 파일
.gitignore.example: Git에서 제외할 파일 설정 예시

3. 실행 방법

터미널에서 실습 파일이 있는 디렉터리로 이동한 뒤 다음과 같이 실행한다.
bash net_check.sh
bash start_server.sh
bash check_server.sh
bash backup.sh
bash check_path.sh
bash search_examples.sh

4. 실습 목적
네트워크 상태 확인, 로컬 서버 실행, 파일 백업 자동화, 파일 검색 및 Git 협업에 필요한 기본 명령어를 익힌다.
